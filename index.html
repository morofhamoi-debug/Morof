Помощь и совместимость

📱 iPhone (Safari)

  • Web NFC не поддерживается. Safari на iOS не предоставляет API для прямого чтения или записи NFC-меток из браузера.
  • Для чтения NFC-меток на iPhone используйте встроенное приложение «Команды» (Shortcuts) — создайте автоматизацию по тегу NFC.
  • Для записи используйте приложения из App Store, например «NFC Tools» или «NXP TagWriter».
  • Это ограничение связано с политикой безопасности Apple и не может быть обойдено из браузера.

🤖 Android (Chrome)

  • Web NFC поддерживается в Chrome 89+ на устройствах с NFC-адаптером.
  • Требуется HTTPS или localhost (безопасный контекст).
  • При первом использовании браузер запросит разрешение на доступ к NFC.
  • Приложите метку к задней панели телефона (обычно в верхней части).

🏷️ Поддерживаемые метки

  • NTAG213 — 144 байта пользовательской памяти
  • NTAG215 — 504 байта пользовательской памяти
  • NTAG216 — 888 байт пользовательской памяти
  • Также поддерживаются другие метки с NDEF-форматированием.

🔒 Безопасность

  • Приложение работает только с обычными перезаписываемыми NDEF-метками.
  • Оно не может читать или изменять защищённые банковские чипы, платёжные приложения или данные Apple Pay.
  • Вся история операций хранится локально в вашем браузере и не отправляется на сервер.

⚠️ Ошибки и их причины

  • «Метка не обнаружена» — поднесите метку ближе или перезапустите сканирование.
  • «Недостаточно памяти» — сообщение превышает объём памяти метки. Сократите данные.
  • «Запись запрещена» — метка защищена от записи или уже содержит данные (при overwrite: false).
  • «Разрешение не получено» — предоставьте доступ к NFC в настройках браузера.
